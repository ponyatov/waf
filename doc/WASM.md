# WASM
## [[WebAssembly]] ISA binary format

The [[waf/WASM|WebAssembly ISA]] was designed to be compact, portable, and secure, with small binary files to reduce download times when deployed as part of a web application.

It’s easy to port the [[vm/bytecode|bytecode interpreter]] to a variety of computer hardware, and it has a secure platform for deploying code over the web.
