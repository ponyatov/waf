# instances
## [[ksy]]

второй блок **instances** - это один из способов описание объектов. 
и типа **s4** (Signed 4 bytes), а также объект **toc,** который находится по адресу “размер файла - 4 + кол-во записей умножить на 144”  
При этом объект **toc** имеет повторяющийся тип **toc_record**, который описан ниже, с числом повторений равным переменной **toc_count.**

```yaml
instances:
    signature:
        pos: 0
        type: signature
```
- pos
	- `pos: _io.size - 4`
		- `_io.size` размер файла
