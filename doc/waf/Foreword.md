# Foreword

With every other language compiling to [[JavaScript]] nowadays, [[WebAssembly]] is the next step in an evolution to break free from these preexisting boundaries.

+ [[WebAssembly]] enables everyone’s favorite language to run on the [[Web/Web|Web]]
+ run not only on the web but on any platform, from [[blockchain]] to edge computing to [[IoT/IoT|IoT]]
- technology is still young and requires some time to mature
