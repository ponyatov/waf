# The Embedding Environment

WebAssembly doesn’t run directly on hardware. You must embed the [[WebAssembly]] binary in a host environment that controls the loading and initializing of a WebAssembly [[waf/module|module]]

we work with
- JavaScript engines, such as [[Node.js]], and 
- web [[browser]]s as embedding environments
- Other environments include [[WASI]], such as [[wasmtime]] (defined shortly)
