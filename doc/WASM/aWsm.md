# aWsm
## An Awesome [[eWASM]] Compiler and Runtime

> _Note: Previously known as [[Silverfish]]_

[[aWsm]] is a compiler and runtime for compiling [[WebAssembly]] ([[WASM/WASM|WASM]]) code into [[LLVM/LLVM|LLVM]] bytecode, then into [[WASM/sandbox|sandbox]]ed binaries you can run on various platforms. It focuses on generating very fast code (best of breed for WebAssembly), having a simple and extensible code-base, and on portability.
