# Who Should Read This Book

- web developers interested in understanding when and why to use [[WebAssembly]]

This book is not specific to writing C/[[Cpp/C++|C++]] or [[Rust/Rust|Rust]], or any other language for WebAssembly; instead, it explores WebAssembly’s mechanisms and capabilities.

Readers should have a basic familiarity with web technologies, such as JavaScript, HTML, and CSS, but don’t need to be experts
